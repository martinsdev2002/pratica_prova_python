# Exercícios de Python

Este repositório reúne exercícios feitos durante o estudo de Python. Os exemplos estão separados por assunto em pastas para facilitar a consulta e a prática.

## Conteúdos

| Pasta | Conteúdo |
| --- | --- |
| [`01_fundamentos`](./01_fundamentos/) | Entrada e saída de dados, variáveis e cálculos |
| [`02_condicionais`](./02_condicionais/) | Decisões com `if`, `elif`, `else` e operadores lógicos |
| [`03_listas`](./03_listas/) | Criação, acesso, atualização, ordenação e operações com listas |
| [`04_aleatoriedade_e_sequencias`](./04_aleatoriedade_e_sequencias/) | Listas aleatórias, contagens, estatísticas e análise de sequências |
| [`05_funcoes`](./05_funcoes/) | Funções, parâmetros, retornos e exercícios com listas |

Os laços `for` e `range()`, contadores e acumuladores aparecem junto dos exercícios em que são usados, especialmente nas pastas de listas e de sequências aleatórias.

## Como estudar

Os exercícios são independentes e alguns ainda são rascunhos. Em certos trechos, os enunciados aparecem como texto fora de comentários e há tentativas que precisam de revisão; por isso, os arquivos não são necessariamente executáveis do início ao fim.

Localize o exercício pelo enunciado, leia o trecho correspondente e execute ou teste apenas essa atividade. Experimente diferentes entradas, incluindo valores-limite e casos em que nenhum item atende à condição.
